# PHASE 0 — 1960년~현재 전체 데이터 소스 검증

작성일: 2026-11-11 · 상태: **1차 검증 완료 / 일부 항목 확인 필요**

검증 방법: 공개 문서·공식 안내·학술 문헌을 웹 검색으로 확인했습니다. API를 직접 호출해 확인하지는 못했습니다. 개발 작업환경의 네트워크가 FRED·ECOS·World Bank·EIA·빅카인즈 도메인을 차단해 `curl` 호출이 모두 실패했기 때문입니다. 따라서 아래 표의 "API 호출 검증" 칸은 모두 **미검증**입니다. 데이터 수집기는 사용자 PC나 서버에서 처음 실행할 때 검증합니다.

## 2. 확인된 핵심 조건

- **빅카인즈**는 1990년 이후 기사만 제공합니다. 그 이전 한국 신문은 네이버 뉴스 라이브러리와 조선 뉴스 라이브러리를 써야 하며, 둘 다 1999년까지 다룹니다.
- **NYT Archive API**는 1851년 이후 메타데이터를 월 단위로 돌려줍니다. 기사 본문은 주지 않으므로 원문 링크로 연결합니다.
- **FRED**는 무료지만 제3자 저작권이 붙은 시리즈는 개인 용도 외에 쓰려면 원 소유자의 허가가 필요합니다. 앱에는 FRED API를 사용한다는 고지와 이용약관 링크가 들어가야 합니다.
- **ECOS**는 무료 인증키로 씁니다. 공공데이터포털에는 무료이고 이용 허락 범위에 제한이 없다고 안내되어 있습니다. 호출 한도는 공식 문서로 다시 확인해야 합니다.
- **한국 국민계정은 1970년을 기준으로 시계열이 끊깁니다.** 1953~1970년은 1953 SNA 구계열, 1970년 이후는 1993 SNA 현행 계열이고, 겹치는 1970년에 4.8% 차이가 납니다. 1960년대 한국 GDP를 1970년대 이후 수치와 직접 비교할 때는 계열이 다르다는 표시를 반드시 붙입니다.

## 4. 기술 제약

- 작업환경에서 외부 데이터 API에 연결할 수 없습니다. 수집기는 코드로 제공하고, 실제 수집은 사용자 환경에서 실행합니다.
- MVP는 **검증된 로컬 시드 데이터(JSON)** 로 동작합니다. 모든 항목에는 출처와 검증 상태가 붙어 있습니다.
- 나중에 FastAPI와 PostgreSQL로 옮겨도 화면은 그대로 쓸 수 있습니다. 같은 인터페이스(DataProvider) 뒤에서 데이터 공급원만 바꾸기 때문입니다.
